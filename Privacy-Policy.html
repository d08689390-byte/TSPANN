🛡️ Privacy & Code of Conduct

Last updated: October 15, 2026

Because the Subdomain Project for Assigned Names and Numbers (TSPANN) encourages deployment on public web infrastructures like GitHub Pages, privacy is built directly into our specification philosophy.

Data Collection & Publishing Philosophy

  • Obfuscation Encouraged: Registrants are actively discouraged from publishing highly sensitive personal tracking data (such as home addresses or primary mobile phone numbers) in public JSON payloads.
  • Role-Based Data: We strongly advise using generic contact proxies, corporate domains, or public social handles within your vcardArray metadata blocks to keep your main personal footprint secure.

Open Source Integrity

To keep the decentralized registry secure, clean, and reliable for all peers on the network, we enforce strict review guidelines:

  • Malicious data formatting or structure injections will be immediately caught and blocked.
  • Intentionally broken routing or malformed target payloads are strictly prohibited.
  • Domain squatting maps intended to hijack namespace without active use will be rejected during peer code review phases.
